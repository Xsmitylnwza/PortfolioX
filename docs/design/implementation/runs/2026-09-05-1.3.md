## Finding and direction

The existing v6 cover combines cyan light trails, a metallic mark, multiple promotional text tiers and a dense terminal capture. The effects compete with the meaningful product behavior: a project owns a Canvas of terminals, and the user can return to or rearrange that scene. The current source explicitly distinguishes restoring layout from launching processes.

| Concept | One-image message | Evidence / signature | Tradeoff |
|---|---|---|---|
| A — Saved Canvas | Return to the project and its pane arrangement | A small authored pane map repeats the arrangement of a large real Canvas frame | Strongest connection to the actual app and its wallpaper/material identity; the wallpaper takes more attention at 120px |
| B — Auto Tile | Reorganize the same terminals into a clear Canvas | Overlapping terminal shapes resolve into the actual four-pane topology | Clearer at thumbnail size; illustrative rather than a screenshot, and focuses on Auto Tile rather than all of Veluma |

Added labels and connectors use white/gray. The actual screenshot in A retains its original color. There are no generated scene assets, invented command output, fake run/success states or claims that opening a project/Auto Tile starts a process.
