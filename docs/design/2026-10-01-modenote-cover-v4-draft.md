## 2. หนึ่งประโยคที่ปกต้องพูด

> **ทุกคำตอบย้อนกลับไปหาประโยคที่พูดจริงได้**
> (English line for recruiters: *Every answer leads back to the moment it was said.*)

เหตุผล: เป็นความต่างที่ตรวจสอบได้ของ ModeNote (source-linked recap/chat + เล่นเสียงตรงเวลานั้น) และตรงกับสิ่งที่วิดีโอ v2 คลิป 04 พิสูจน์แล้ว ไม่ใช่การอ้างความแม่นยำหรือความเร็ว (A13, A20)

## 4. สามแนวให้เลือก

### A · Quote → Chip (ใช้ตัวอักษรเป็นภาพ)

```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│  “อยากลองรวมรายการงาน                                     │
│   ไว้จุดเดียว แล้วเช็กทุกเช้า”          ← ข้อความใหญ่ 96px │
│   ▌ marker เส้นซ้ายสี primary                             │
│                                                          │
│   ( ▶ 0:44 )  ← chip จริง ขยาย 3x, สีทึบ primary          │
│     │                                                    │
│     └──── ถ้าจะเริ่มแก้ ควรเริ่มตรงไหน?  → คำตอบ (เล็ก)    │
│                                                          │
│  [buddy] ModeNote     Every answer leads back to the     │
│                       moment it was said.                │
└──────────────────────────────────────────────────────────┘
```

- **ความรู้สึก:** เงียบ แพง แบบ editorial นิตยสาร (A17)
- **จุดแข็ง:** ไม่มีอะไรเกินจำเป็น ประโยคไทยตัวใหญ่ทำให้ไม่เหมือนปก SaaS ทั่วไป
- **ความเสี่ยง:** ถ้าไม่มี UI คนอาจไม่รู้ว่าเป็นแอป แก้ด้วยการใช้ chip เวลาที่เป็น UI จริงเป็นจุดหลัก

### B · Session timeline (ใช้ diagram เป็นภาพ) — **แนะนำ**

```
┌──────────────────────────────────────────────────────────┐
│  ModeNote  [buddy]                                       │
│                                                          │
│   ┌ ปัญหาหลักคืออะไร? ┐  ┌ เหตุการณ์ไหนชัด? ┐  ┌ เริ่มแก้ตรงไหน? ┐  ← คำถาม 3 ข้อ │
│        │                      │                 │       (การ์ดเล็ก)│
│  0:00 ─┼──────●────────●──────┼──●──────────────●──────── 1:00 │
│        0:10  0:18     0:28   0:32          ( ▶ 0:44 )         │
│                                               │ สีทึบ primary    │
│        “อยากลองรวมรายการงานไว้จุดเดียว แล้วเช็กทุกเช้า”         │
│                                                          │
│  Every answer leads back to the moment it was said.      │
└──────────────────────────────────────────────────────────┘
```

- **ความหมาย:** เส้นเวลาของ session ยาวเต็มความกว้างปก จุดบนเส้นอยู่ตามเวลาจริงของ fixture คำถามแต่ละข้อมีเส้นลากลงไปยังเวลาที่เป็นหลักฐาน และมีเพียงจุด 0:44 ที่เป็นสีทึบพร้อม quote
- **ทำไมแนะนำ:** เป็นรูปทรงที่ ModeNote เป็นเจ้าของคนเดียว (หน่วยความจำที่ผูกกับเวลา) ที่ 120px ยังเห็นเป็นแถบแนวนอนกับจุดสีส้มจุดเดียว จึงต่างจากปกอื่นใน gallery ได้ทันที (A22) และทุกเส้นมีความหมายจริง
- **ความเสี่ยง:** ถ้าทำไม่ดีจะดูเหมือน infographic แก้ด้วยการใช้แค่ 3 ระดับน้ำหนัก (หมึก, เทา, primary จุดเดียว) และไม่ใส่ไอคอน

## 6. วิธีตัดสินว่าผ่าน

- **3 ขนาด:** 1600px (รายละเอียดคม ไม่มีอะไรทับกัน), 240px (อ่าน "ModeNote" และเข้าใจรูปทรงหลักได้), 120px (รูปทรงไม่ซ้ำกับปกอื่น)
- **ในบริบทจริง:** ดูใน gallery ห้องดำ/แดงและใน case hero (`object-fit: contain`, 8:5) ที่ 1910×783, 1458×856, 390×844
- **ทดสอบ 5 วินาที:** ให้คนที่ไม่รู้จักโปรเจกต์ดู แล้วถามว่า "แอปนี้ช่วยอะไร?" คำตอบที่ต้องการคือประมาณ "ย้อนกลับไปหาสิ่งที่พูดได้"
- **Blind A/B:** วางเทียบกับ v3 ที่ขนาดเท่ากันโดยไม่บอกว่าอันไหนใหม่ (ใช้ `design-ab-loop` ได้)
- **Checklist anti-slop:** ไม่มี gradient/glow/tape/tilt, tagline 1 ประโยค, ทุกเส้นเชื่อมของจริง, ทุกข้อความอ่านได้ที่ 100%, ไม่มีตัวเลขที่ verify ไม่ได้
