# YouTube launch thumbnails — reference research

**ModeNote correction:** the analog reel/paper trial was rejected as not clearly a software product. Its revised preview leads with actual recording settings, session library and source transcript. The takeaway from launch thumbnails is to expose product-specific interactions and context, not let a physical metaphor dominate the software.

**Preview follow-up:** the creator accepted the FreeFlow direction as fitting its product identity. A [ModeNote preview](http://127.0.0.1:5173/design/project-covers/modenote-ui-preview/) now applies the method with copper audio materials, original transcript UI and a source-linked quote. It remains a separate review item, not an accepted or integrated production cover.

**Latest application of this research:** the actual web application must be visible and understandable; logos and materials support it. The creator asked to try **FreeFlow only**, allowing imagegen for detailed background elements. The [FreeFlow preview](http://127.0.0.1:5173/design/project-covers/freeflow-ui-preview/) combines real document-library and client-chat UI with a generated blue paper dossier. [Source and review notes](../../design/project-covers/freeflow-ui-preview/README.md). Earlier suggestions for an object/logo with only tiny UI are superseded. Production covers have not been replaced by this preview.

Latest request: find the actual cover images of YouTube videos introducing products or new features, like Apple and Google. Website hero sections and frames within a video do not satisfy this brief. No new artwork is produced in this research step. FreeFlow, ModeNote, Veluma and Keshi version 3 remain rejected; retain Hermes direction.

[Open the visual reference board](http://127.0.0.1:5173/design/references/youtube-launch-thumbnails/).

23 actual thumbnails were visually inspected. Nine were selected for distinct, applicable treatments. Search renderer data provides the thumbnail URL and video identity; YouTube oEmbed independently confirms each selected title/channel. The board embeds the remote thumbnails unchanged and links to each video. Analysis concerns the thumbnail alone, not the video's production process or measured click-through performance. Thumbnails may change after this access date, 5 September 2026.

| Actual video | Visible design choice | Application to explore |
|---|---|---|
| [Introducing Raycast Focus](https://www.youtube.com/watch?v=NZwqx_dS-k0) | A single tilted timer icon with glass thickness, reflection, directional shadow and a small timer fragment | Concentrated material detail for FreeFlow's central dossier or Keshi's timer, with their own color/material identity |
| [Raycast Notes is Finally Out](https://www.youtube.com/watch?v=6knS3y39f7k) | Layered note mark, controlled edge light, restrained background | ModeNote paper depth and character treatment; preserve Buddy rather than importing Raycast's T mark |
| [Introducing iPhone 17 Pro](https://www.youtube.com/watch?v=_-AS5DtDeqs) | Enlarged camera/material detail with matching PRO typography | FreeFlow's object close-up, vivid blue material and distinctive F; avoid spreading attention over many mini-documents |
| [Introducing iPhone Air](https://www.youtube.com/watch?v=M0au92yebLQ) | Side profile and a hand make thinness perceptible | Choose a view that demonstrates one product property before adding explanatory copy |
| [Introducing Flow](https://www.youtube.com/watch?v=A0VttaLy4sU) | A wave vortex and central word form one dominant image | Veluma's real Canvas atmosphere should occupy the scene; do not borrow a wave as arbitrary decoration |
| [Introducing Tools in Google Flow](https://www.youtube.com/watch?v=vN6W1Z8eRMc) | Selected output fragments and tool controls surround a clear central title | Multi-feature compositions need specific finished content, scale variation and a single hierarchy |
| [All the launches at Config 2025](https://www.youtube.com/watch?v=NHodnYFUT_I) | Oversized rough-line character and halftone, with a smaller brush palette | ModeNote Buddy should perform a meaningful action with voice/notes; develop drawing character and material, not merely enlarge the logo |
| [Introducing Arc for iPhone](https://www.youtube.com/watch?v=kEE8GhLy6U4) | Landscape and travelling vehicle support “Bring home with you” | Veluma's human workspace vision: integrated tools inside a personal scene, not isolated icon coins beside a screenshot |
| [A New Start — Raycast for Windows](https://www.youtube.com/watch?v=QTcUR5BjN2M) | Nostalgic Windows Start object and clouds form a coherent cultural reference | Keshi's existing radio/scrapbook/music atmosphere can drive the composition; avoid framing a full screenshot with extra labels |

The transferable principle is to choose real product content that explains the application, give it a clear visual hierarchy, and support it with subject-specific materials, lighting and brand identity. Actual UI must remain a significant part of the image. Keep authentic logos and app colors. Review the artwork at thumbnail size without its explanatory paragraph; passing render checks alone does not establish design acceptance.
